Grammar

Records in, folds and ticks out, lenses back to text. Thirteen nouns, twelve verbs and six layers, each a little higher off the ground and a little more temporary. Everything said is a record on the ground; everything above it is worked out, and can be thrown away and worked out again.

proveda theorem in model/Laws, pinned by vectorssettleddecided in the design ledger, not built yet

A record is one sentence

The envelope is the grammar of a single observation: who saw, what sort of thing they saw, of what, when, and what it replaces. The core reads every word of it and nothing else.

The payload is the sentence's content. The core never interprets it, so it can be withheld or erased and the sentence still parses: its id, its place in the chain and every test on its envelope hold.

Nouns

Each noun has one purpose, its own state, and an operating principle: what happens, step by step, when you use it. The laws under each card are the theorems that hold it to its principle.

record

proved
Purpose
Say one thing an observer saw, so anyone can check it and nobody can change it.
State
An envelope the core reads, a payload it never interprets, a signature. Named by r: and a hash of the envelope and the payload's commitment.
Principle
Its id hashes what it says, written canonically: spell a set another way and the id doesn't move. Erase its payload and the id, the signature and every record citing it still hold.

record.erasure record.sets write.checked

observer

proved
Purpose
Say who saw it.
State
A typed reference on every record, usually a lineage id sl:….
Principle
Nothing a record says is true; it is said, by its observer. Two observers disagreeing is two records, both kept.

Keys checked at read, and standing, arrive in step 3.

record.refuse

thing

proved
Purpose
Give each subject its own state, so records about different things never interfere.
State
A typed reference, prefix:value, in a record's about. A record about nothing anchors a thing named by its own id.
Principle
Revise a thing's record and the revision is its head. Revise one record twice and the thing has two heads, a fork, until a record names both.

thing.local admit.no-cross

store

proved
Purpose
Hold records, and nothing else: it owns no meaning.
State
A set of records, kept in places, each record one canonical line.
Principle
A store is a set. Read its places in any order and a reader settles the same records, one per id.

input.union settle.set

view

proved
Purpose
Let readers who hold different payloads still agree on what is current.
State
What one reader holds: each record with its payload, withheld, or erased. Envelopes are always held.
Principle
A view folds to the same heads as a reader holding everything. What it can't read it counts as unread, never guesses.

view.no-resurrection result.unread

spec

proved
Purpose
Write a standing question as data anyone can check.
State
vertex, the sources in from, the slots in fold.
Principle
An accepted spec's parsed form parses back to itself. A refused one names the first rule it breaks, and where.

spec.parse

source

proved
Purpose
Choose records by their envelopes alone.
State
A store, then optionally the kinds and the thing it is about.
Principle
A source takes a record when its kind is listed and it is about the thing. A view selects exactly the same records.

spec.select spec.from-thing

slot

proved
Purpose
Hold one answer.
State
A name, one fold, and optionally where, follow and limit.
Principle
The same set of records gives every slot of every spec the same value. A slot over heads never brings back a superseded record.

spec.set spec.after-supersession

fold

proved
Purpose
Turn a set of records into state.
State
One of six: count, sum, min, max, in the accumulating family; latest-by, over heads; and collect, over heads when it follows prev and over every selected record when it doesn't.
Principle
The set decides: arrival order and two-way syncs never change the answer, and a late record folded onto the cached state gives what folding the whole set again gives.

acc.set heads.set latest-by.converge

vertex

proved
Purpose
Ask a standing question over stores: select, fold, tick.
State
A spec run over what a reader holds.
Principle
Run it on the same set and it gives the same slots, each with how many records it couldn't read.

Naming a vertex by its spec's hash, and when it ticks, are settled, not built.

spec.set result.unread

tick

settled
Purpose
Fix a vertex's result at a moment, so others can cite it.
State
The vertex, the records it covers, listed exactly, and the result; an id over all three.
Principle
Anyone holding the covered records recomputes the same tick.

lens

proved
Purpose
Turn state into text people edit, and edits back into records.
State
A render, a parse and a diff by ids; the base the text came from.
Principle
Parse a render and you get back what was rendered. A dropped section changes nothing: absence is never an edit.

Keyed sections are proved; applying edits as records is settled.

lens.round-trip lens.absence-not-edit

grant

settled
Purpose
Give standing ahead of time, with a scope.
State
A record; a record acting on it names it in under.
Principle
A record without standing stays visible but has no effect.

Verbs

Two verbs write: emit and tick. Every other verb reads, and reading never changes a store. A lens closes the loop the only way anything gets down to the ground: its edits become records.

Most of what feels like an action is a construction, an emit with a field filled in. Revising, merging and erasing are sentences, not new verbs.

Constructions

start

emit with no prev

A new chain. About nothing, the record anchors a thing of its own.

revise

emit with prev: [x]

Replace x within a thing both are about. Naming one about other things is refused, prev-unrelated.

fork

two records naming one prev

Nobody's verb: a state. The thing has two heads, both shown, the newer by content order winning.

merge

emit with prev: [x, y]

One head again.

erase

emit with erases: [x]

Any kind may. x keeps its id, signature and place; only its opening goes.

withhold

hold a record without its payload

Not a write at all: a view. Envelopes still answer every test on them.

Layers

Six layers, each as high as it is temporary. The ground is what was said; nothing on it is ever edited. Each layer above is worked out from the one below it, so any of them can be dropped and rebuilt.

Every arrow up recomputes. The only arrow down is a record.

A walk

One decision, nine steps: two people write, fork, merge and erase; a reader with less sees the same; a vertex ticks; a lens turns the result into text and an edit back into a record.

    Where nouns meet verbs
