# The typefaces

The front page serves three typefaces from this directory, so that a reader's visit is not reported to a font host. Each is under the SIL Open Font License, version 1.1, which allows it to be bundled and redistributed with this site. The files are the Latin and Latin Extended subsets as Google Fonts served them on 2026-11-27, unchanged.
